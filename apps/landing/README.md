# @wordlex/landing

The marketing page at `wordlex.afiefabd.com`. Next.js, because it is a document that needs
to be indexed and to render fast from the server (ADR 0001).

```sh
pnpm dev            # http://localhost:3000
```

`AGENTS.md` and `CLAUDE.md` here are written by `next dev` and will come back if
you delete them. Leave them.

With Daily-only play, a visitor who clicks through gets exactly one Game and then
waits until tomorrow — this page has to sell the ritual, not the immediacy.
