# @wordlex/play

The game, at `play.wordlex.afiefabd.com`. TanStack Start, so the Track lives in typed
search params — `/?lang=jv&length=7` — and the day's board is in the HTML on first
paint (ADR 0001).

```sh
pnpm dev            # http://localhost:3001
```

A junk or stale URL falls back per field rather than erroring: `?lang=jv&length=99`
keeps Javanese and drops to 5 letters.

React Compiler runs here through oxc rather than Babel (ADR 0017). `routeTree.gen.ts`
is generated by the Start plugin — committed, but never edited by hand.

Components come from `@wordlex/ui`. Add new ones with
`pnpm dlx shadcn@latest add <name> -c packages/ui`, not into this app.
