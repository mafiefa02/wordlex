# @wordlex/play

The game, at `play.wordlex.afiefabd.com`. TanStack Start, so the Track lives in typed
search params — `/?lang=jv&length=7` — and every pill in the Track bar is a real link.

```sh
cp .env.example .env
pnpm dev            # http://localhost:3001
```

It needs `apps/api` running, and the API needs a migrated and seeded database —
the root README has the sequence.

A junk or stale URL falls back per field rather than erroring: `?lang=jv&length=99`
keeps Javanese and drops to 5 letters.

## The board is fetched, not server-rendered

The Game token is `httpOnly` and host-only to the API's origin (ADR 0022), so the
browser never sends it to this app and this app's server has no way to know which
Game a visitor is playing. What is server-rendered is the shell — header, Track
bar, an empty board of the right shape — and `GET /daily/:language/:length` fills
it in on mount. The empty board is the honest starting state anyway, so there is
no flash of the wrong thing. ADR 0001 promised otherwise and is amended at the
top to say so.

## How a Game starts

Typing needs no Game. The first Enter sends `POST /guess`, gets a 401 because a
Guess never creates a Game (ADR 0022), then sends `POST /game` and repeats the
Guess **with the same `Idempotency-Key`** — a second uuid there would spend a
second row. The start key is held per Track for the life of the visit, so two
presses collapse into one Game rather than two (ADR 0024).

Nothing creates a Game on arrival. A Game with no Guesses is Abandoned (ADR 0026)
and would pollute every Answer's Solve Rate.

## The Answer

A lost Game does not print the Answer until its WordleX Day is over, even though
the API sends it as soon as the Game ends. Everyone is on the same Daily, so a
screenshot posted at noon would spoil it for everyone who has not played — and
the result sheet is built to be screenshotted.

## Motion

`src/app.css` holds the board's keyframes, all gated on `motion-safe`. All of it
is one-shot bar one: `row-waiting`, the wave the live row runs while a Guess is
out. A request of unknown length is the one thing a fixed number of runs cannot
describe — anything else finishes, and then a slow Guess looks like a dead one.
It moves `opacity` and `translate` alone, runs only while a request is actually
in flight, and falls back to a static dim under `prefers-reduced-motion`. It is
the only exception; the note at the top of `app.css` says so, and ADR 0030 says
why.

The Tile waiting for a letter still has a ring rather than a caret, which would
repaint for as long as the board is open rather than for as long as a request
is.

React Compiler runs here through oxc rather than Babel (ADR 0017). `routeTree.gen.ts`
is generated by the Start plugin — committed, but never edited by hand.

Components come from `@wordlex/ui`. Add new ones with
`pnpm dlx shadcn@latest add <name> -c packages/ui`, not into this app.
